# Roadmap
- **M1 Foundation** (done): monorepo, Electron shell, server, settings, logging, tests, build scripts.
- **M2 Tablet connection**: opt-in LAN hosting, URL + QR code, 4-digit pairing code, sessions, WebSocket, reconnect, disconnect clients.
- **M3 FSUIPC proof of concept**: typed simulator adapter, FSUIPC7 WebSocket server adapter, verified offsets, mock adapter for tests.
- **M4 CabinView**: `/cabin` route with live telemetry, map placeholder, disconnected and stale states.
- Later: SimBrief, weather, checklists and profiles, GSX Pro, charts, VATSIM, performance, logbook.
